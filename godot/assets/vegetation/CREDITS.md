# Vegetation model credits

The following model files are bundled as base64 text and decoded at runtime by Godot:

- `tree1.glb.b64` — CommonTree 1
- `tree2.glb.b64` — CommonTree 2
- `tree3.glb.b64` — CommonTree 4
- `bush.glb.b64` — Bush_Common

**Original asset source:** Quaternius, [Stylized Nature MegaKit](https://quaternius.itch.io/stylized-nature-megakit).

**License:** CC0 1.0 (public domain dedication), as identified in the source asset repository's `CREDITS.md` at [anshaneja5/skyline-run](https://github.com/anshaneja5/skyline-run/blob/main/CREDITS.md).

The models are third-party assets. The game's other code and original procedural content are separate from these model files.
